# 今天应该穿什么呢？— 换装小游戏

轻量纯前端网页换装游戏（HTML5 + CSS3 + 原生 JavaScript，无后端）。
**双击 `index.html` 即可游玩**，也可部署到任意静态托管。

## 文件结构

```
换装小游戏/
├── index.html          # 入口（双击打开）
├── css/style.css       # 全局 + 封面 + 房间
├── js/
│   ├── main.js         # 入口 + 页面状态机
│   ├── state.js        # 存档读写（localStorage）
│   ├── items.js        # 服装目录（内联数据，layer 由 category 决定）
│   ├── assets.js       # 程序化占位素材（时装画人体比例 + 卧室背景）
│   ├── renderer.js     # 图层渲染引擎（z-index / 互斥 / 配饰叠加）
│   └── i18n.js         # 中文 / 意大利语切换（localStorage: dressup_lang）
├── data/items.json     # 服装目录参考副本
└── assets/             # （未来）正式 PNG 素材目录，与 items.js 路径对应
```

## 关键设计约定（评审修复项已落地）

1. **数据内联**：服装数据在 `items.js` 中，不依赖 `fetch(items.json)`，
   保证双击打开即可玩。
2. **初始金币统一为 100**（规格书 7.1 规则优先于示例数值）。
3. **`lastCoinTick` 新建存档时初始化为当前时间**，防止金币计时爆炸。
4. **占位素材可无缝替换**：往 `assets/` 放入与 `items.js` 中 `src`
   路径一致的正式 1000×1400 PNG 后，游戏自动优先使用真实图片
   （加载失败自动回退占位图），代码零改动。

## 如何替换正式美术

1. 按规格书 3.1 绘制 1000×1400 透明 PNG（身体、发、每件服装）。
2. 按 `items.js` 中 `src` 的路径命名放好。
3. 刷新页面即生效；不想用的衣服删掉对应文件即可回退占位图。

## 技术要点

- 渲染：绝对定位图层叠加，`object-fit: contain` 对齐。
- 数据：穿搭/金币/已拥有 → localStorage；自定义服装图片（阶段7）→ IndexedDB。
- 兼容：现代 Chrome / Edge / Safari / Firefox，PC + 手机自适应。
